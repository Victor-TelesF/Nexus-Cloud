# Análises em Jupyter

Crie seus arquivos `.ipynb` nesta pasta e abra-os pelo VS Code com a raiz **Nexus-Cloud** aberta. Use o kernel Python de `.venv`. O diretório de execução já está configurado como a raiz do repositório, inclusive para notebooks em subpastas.

O preparo do ambiente, a conferência dos caminhos e a execução do Streamlit estão no [guia do ambiente de análise](../docs/06-ambiente-analise.md). Vincule cada tentativa e seus resultados ao [checklist](../docs/03-progresso.md).
